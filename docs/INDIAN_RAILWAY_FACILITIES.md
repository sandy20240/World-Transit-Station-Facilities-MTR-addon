# Indian Railway Facilities Pack

This branch adds the prepared Fabric/MTR Indian Railway facilities resource package for WTSF.

## Compatibility
- Minecraft 1.20.1
- MTR 4.0.5
- Fabric Loader 0.15.11
- Fabric API 0.92.2+1.20.1
- Architectury 9.2.14
- Java 17

## Included facilities
- Indian Railway station signs
- Platform signs
- Ticket counter
- Ticket vending machine
- Reservation counter
- Platform bench
- Station clock
- Water point
- Dustbin
- Chai stall
- Food stall
- Toilet

The prepared package contains blockstate JSON, block/item models, English language entries, and texture PNGs. It is intended as a resource/model layer for the existing WTSF MTR addon; Java block/item registration remains part of the integration work.
