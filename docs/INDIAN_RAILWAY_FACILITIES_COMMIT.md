# Indian Railway Facilities

Prepared for WTSF / Minecraft Transit Railway.

Target: Fabric, Minecraft 1.20.1, MTR 4.0.5, Java 17.

Facilities: station sign, platform sign, ticket counter, ticket machine, reservation counter, platform bench, station clock, water point, dustbin, chai stall, food stall, toilet.

This commit records the integration target. Binary ZIP assets are intentionally not imported into the repository.
